# Share 目录说明

`share/` 与 `server/`、`client/` 同级，保存客户端和服务端共同依赖的稳定契约源文件。这里不放服务实现、客户端运行时代码或构建生成文件。

## 目录职责

```text
share/
└── proto/
    ├── client/    客户端与服务端之间的公开协议和业务错误码
    ├── internal/  服务之间的私有协议
    └── store/     服务端持久化数据结构
```

## 使用规则

- `.proto` 是协议的唯一源文件，生成的 C++、GDScript 或其他语言代码进入各自构建输出目录，不提交到 `share/`。
- `proto/client` 可以由客户端和服务端共同消费；服务端基础设施错误码不得直接暴露到该协议。
- `proto/internal` 只用于服务间通信，客户端不得依赖。
- `proto/store` 定义持久化 blob，不作为客户端网络协议使用。
- 移动或重命名协议文件时，必须同步检查 CMake、客户端生成流程、服务代码、测试和文档引用。
