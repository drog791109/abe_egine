# 游戏策划文案 (GDD) v1.0版：【万物造化】

## 1. 游戏概述与底层架构

- **游戏类型：** 横版拟真网格构筑 / 多职业修仙 RPG / 强经济生态模拟 / 爽感副玩法融合。
- **核心设计哲学（系统降维）：** 砍除繁杂的 UI 面板（无铁匠铺、强化炉界面）。所有交互收束于横版屏幕左侧的“二维网格储物袋”中，通过物理拖拽完成一切资源转化。表现层（VFX/UI）与逻辑层（二维Matrix状态机）彻底解耦，确保满屏特效时帧率绝对稳定。
- **UI 与视觉布局（全横版拟真设计）：**
  - **右侧（战斗验证区）：** 横版卷轴式的实时自动战斗展现。角色在大世界中穿梭，战力提升与特效变化实时无缝反馈。
  - **左侧与中央（物理交互区）：** 角色腰间的【储物袋】向身侧展开为半透明的网格阵列，正中央镶嵌着不可移动的【本命阵眼】。

## 2. 核心系统一：本命阵眼与天生词条（极速外挂反馈）

这是整个网格构筑的灵魂。储物袋正中央的格子被设定为【金手指阵眼】，开局随机赋予极其逆天的“本命词条”。

- **物理触发机制：** 任何物品只要被拖拽到该格子上，或与该格子产生灵气连线，瞬间触发逆天效果。
- **词条举例：**
  - **【造化双生】：** 将极品材料拖入，相邻空位瞬间复制出一个完全相同的极品。
  - **【杀伐真意】：** 武器置于阵眼，右侧横版战斗区角色的基础攻击力瞬间翻倍，刀刀猩红暴击。
- **长线追求（境界重构）：** 每次跨越大境界突破（如筑基跨越至结丹），游戏进入“暗屏时空凝滞”，全屏爆发碎屏特效，玩家可在三个全新/进阶的逆天词条中进行“三选一”重构，或者砸碎极品“逆命丹”强制洗炼阵眼。

## 3. 核心心流：30分钟“天崩到逆袭”的情绪过山车

游戏不采用平铺直叙的推图，而是通过动态事件驱动，将体验切割为严密的“30分钟高低谷心流闭环”。

- **第一阶段（0-5分钟）【打压天崩】：** 玩家处于劣势（如被高级 NPC 追杀、被贴上倒计时绝杀印记），右侧高压敌人逼近，左侧储物袋被清空或封锁，情绪触底。
- **第二阶段（5-20分钟）【意外暴富】：** 绝境中将几块废料拖入【本命阵眼】，意外触发金手指漏洞，跨境界合成出残缺帝兵或九转金丹。玩家利用系统规则在极短时间内滚雪球，聚敛海量战力。
- **第三阶段（20-30分钟）【极致打脸】：** 仇家降临右侧横版战场，玩家不慌不忙将刚刚合成的“跨界神装”拖入装备槽。全屏强制顿帧（Hit Stop），释放贯穿屏幕的毁灭特效，一击秒杀反派。满屏战利品爆出，自动填满左侧网格，情绪达到巅峰。

## 4. 破冰与解压引擎：副玩法融合（Daily Minigames）

为了在30分钟的重度脑力博弈（网格连线、拍卖行倒买倒卖）之余调节多巴胺，引入极低操作门槛、极高视觉爽感的“每日副玩法”。该玩法采用全横版跑酷/拖拽模式，主要用于**产出扩充网格容量的稀有材料（空冥石）\**与\**底层通用货币**。

### A. 动态倍增流：【剑意长河】（极致割草）

- **视觉表现：** 横版弹幕跑酷。玩家操控一柄本命飞剑从左向右疾驰。
- **玩法逻辑：** 路上出现修仙阵法门。穿过蓝色的【剑气 +50】，飞剑旁瞬间裂变出50把幻影飞剑；穿过金色的【阵法 $\times 3$】，飞剑数量呈指数级满屏暴涨。玩家需要避开红色的【剑煞 -20】障碍。
- **终极释放：** 到达横版关底，面对血条极厚的一阶上等大妖。玩家积攒的成百上千把飞剑如洪流般倾泻（万剑归宗），大妖血条数字疯狂跳水直至清零爆金币。

### B. 数值吞噬流：【万妖图录】（滚雪球逆袭）

- **视觉表现：** 横版多节点地图，纯粹的数字比拼与物理拖拽。
- **玩法逻辑：** 玩家操控一只初始标有数字（代表战力值，如 50）的灵兽。用手指在横版地图上拖拽，吞噬数值小于自己的妖灵（如 30），吞噬后自身数值瞬间变为 80。
- **降智与诱惑：** 关卡故意设计极其悬殊的路线，利用玩家的“纠错强迫症”和“干预冲动”，让玩家迅速规划出一条从 50 吃成 5000 的绝佳路线，最后一口吞掉终点处战力 4999 的远古巨兽。

## 5. 经济生态：多元身份与双轨制市场

游戏拒绝单机推图，打造一个基于网格特化和资源流转的修仙社会。

- **网格特化身份：**
  - **劫掠者（打家劫舍）：** 初始拥有高阶【破坏阵眼】，通过战斗掠夺获取硬通货。
  - **炼丹师（深加工）：** 网格自带【混沌炉】，将低级灵草合成为能够刷新金手指词条的“逆命丹”。
  - **寻脉者（挖矿）：** 初始网格容量极大，盛放海量基础原矿。
- **双轨制市场：**
  - **官方商店：** 维持底层物价底线，提供基础边角料回收（依靠副玩法产出的货币购买）。
  - **拍卖行：** 核心经济中枢。炼丹师产出的极品逆命丹、劫掠者抢来的绝世功法，全在此动态竞价，形成完美的“生产 $\rightarrow$ 消耗 $\rightarrow$ 暴富”的经济闭环。

## 6. 长线终极目标：大帝之巅与法则降维

- 从炼气期一路直达大帝境。后期的数值将是百亿、千亿级别的跨度（底层采用独立大数算法支撑）。
- **法则降维打击：** 随着境界拔高，左侧的网格将迎来规则进化。例如达到“圣人境”后，网格可自动吞噬并批量连线低级材料；达到“大帝境”后，副玩法【剑意长河】可开启自动扫荡碾压。将玩家的注意力彻底解放，倾注于更高维度的法则推演与世界博弈中。
