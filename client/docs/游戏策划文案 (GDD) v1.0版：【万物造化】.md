本版将游戏重新定义为：**一款以探索为驱动、以“规则收集”为成长核心的横版修仙 Rogue-lite。**

修仙负责包装世界观，探索负责制造惊喜，规则负责构成成长。玩家每次进入未知区域，都可能发现一条能够改变物品、技能、地图、敌人或资源关系的新规则。

# 游戏策划文案 (GDD) v1.1 方向修订版：【万物造化】

## 0. 产品重新定义

### 0.1 一句话定位

> 一款以探索为驱动、以“规则收集”为成长核心的横版修仙 Rogue-lite。

### 0.2 核心体验

玩家进入未知区域，发现机缘、秘境、遗迹和 Boss，从探索中获得能够改变系统行为的规则。规则不是单纯增加攻击力，而是改变物品、技能、地图、敌人和资源之间的关系。

核心循环为：

> **探索未知 → 发现规则 → 组合规则 → 形成 Build → 验证规则 → 获得更深层的探索能力。**

灵根是初始倾向，功法是规则组合，法宝是规则载体，境界是规则容量和规则复杂度的提升，飞升是对世界底层规则的突破。

### 0.3 真正的差异化

- 不以功法数量作为主要内容指标。
- 不以攻击力、金币或吞噬数字的大小作为最终追求。
- 不以固定任务链作为探索的唯一驱动力。
- 不把本命阵眼设计成一次性的无条件外挂。

真正的创新点是：**每次探索，都可能获得一条改变整个成长体系的新规则。**

## 1. 四类体验参考与转化原则

以下作品只作为体验目标参考，不直接复制其题材、界面、数值或内容。

| 参考方向 | 学习内容 | 在《万物造化》中的转化 |
| --- | --- | --- |
| Balatro | Modifier 规则倍增 | 收集会修改规则的法则词条，通过条件、触发器和转化效果形成联动。 |
| Vampire Survivors | 自动技能组合与屏幕爽感 | 玩家主要做探索、选择和构筑，战斗自动执行规则组合，并用清晰的连锁反馈制造爽感。 |
| Path of Exile | 成长树、词缀和 Build 多样性 | 用法则树、物品词缀和规则冲突形成多条成长路线。 |
| Terraria | 探索驱动成长 | 地图、环境、秘境和 Boss 负责制造发现，新规则同时解锁新的探索方式。 |

### 1.1 四条设计原则

1. **规则优先于数值**：数值是规则产生的结果，规则才是玩家收集和研究的对象。
2. **探索优先于任务**：任务用于提示方向和塑造剧情，不能替代玩家主动发现。
3. **构筑优先于职业**：玩家可以从初始倾向出发，但不被固定职业锁死。
4. **爽感必须可读**：效果可以夸张，但玩家必须看懂是哪条规则触发了什么结果。

### 1.2 横版视觉布局

- **右侧战斗验证区**：展示横版卷轴式自动战斗，突出规则链和技能组合。
- **左侧探索交互区**：展示地图、资源、秘境入口和规则提示。
- **中央法则构筑区**：展示储物袋、法则网格和本命阵眼，支持拖拽和连接。

## 2. 核心系统：规则收集与法则构筑

### 2.1 规则的基本结构

每条规则尽量由以下部分组成：

> **触发时机 + 作用对象 + 条件 + 规则变化 + 代价或限制**

例如：物品进入阵眼时，若相邻存在三个同类物品，则下一次技能触发时复制一次，但每次探索只能触发一次。

玩家获得的不是“攻击力 +20%”，而是一条可以与其他规则继续组合的系统语句。

### 2.2 规则类别

- **Modifier（修正规则）**：改变数值、范围、数量、目标或触发次数。
- **Trigger（触发规则）**：定义什么时候启动效果，例如拾取、受伤、移动、击杀或进入新区域。
- **Condition（条件规则）**：定义规则成立的环境，例如低生命、夜晚、相邻同类物品或特定地形。
- **Transform（转化规则）**：改变物品类别、技能形态、资源用途或敌人状态。
- **Link（连接规则）**：把规则、物品和技能组成可传递的链路。
- **Cost（代价规则）**：用生命、空间、速度、资源或其他能力限制强力组合。

### 2.3 本命阵眼：规则编译器

本命阵眼不再是固定的“金手指外挂”，而是玩家的规则编译器：

- 开局只提供一条基础规则和有限的规则槽位。
- 探索中获得的规则可以放入阵眼、法则网格或物品上。
- 规则的位置、相邻关系和连接方向会影响最终效果。
- 境界提升增加的是规则容量、连接方式和规则层级，而不是单纯提高攻击力。

### 2.4 规则组合示例

- **剑意流**：击杀 → 生成剑意 → 达到阈值 → 复制飞剑 → 飞剑击杀范围扩大。
- **逆境流**：生命低于 30% → 伤害转化为护盾 → 护盾破裂时释放范围技能 → 击杀后恢复生命。
- **炼化流**：采集普通材料 → 材料带有“残缺”标签 → 三个残缺材料融合 → 转化为随机规则碎片。

每个 Build 都应有明显优势、明确弱点和可被探索内容补强的方向，避免无限制叠加单一强度。

## 3. 核心游玩循环：探索制造惊喜

### 3.1 单次探索循环

1. **选择方向**：从地图、天气、传闻、已知规则和风险奖励中决定前往哪里。
2. **进入未知区域**：探索地形、资源点、隐藏入口、随机事件和可交互环境。
3. **发现规则线索**：通过遗迹、NPC、怪物行为、环境谜题或 Boss 机制获得规则碎片。
4. **做出取舍**：选择立即装备、带回研究、与已有规则融合，或放弃当前收益换取更大风险。
5. **组成 Build**：在储物袋和法则网格中安排规则、物品和触发关系。
6. **自动验证**：进入战斗或事件，让规则组合自动运行并产生结果。
7. **继续探索**：新规则改变可到达区域、可处理环境和可挑战的 Boss。

### 3.2 节奏目标

“30 分钟一个闭环”保留为短时体验目标，但不再是强制倒计时。一次完整探索应包含：

- 至少一次可感知的规则发现。
- 至少一次规则组合或 Build 调整。
- 至少一次由新规则改变结果的战斗、事件或路径。
- 至少一个值得下次继续探索的未知线索。

### 3.3 Rogue-lite 的局内与局外成长

- **局内成长**：本次探索获得的规则、临时词缀、资源和 Build 组合。失败后大部分局内强度消失，保证每次重新组合都有意义。
- **局外成长**：规则图鉴、世界线索、永久探索工具、基础规则槽位和新的区域入口。它们保留玩家的发现，不直接替代局内构筑。
- **重复探索价值**：区域布局、机缘组合、Boss 规则和可用规则池发生变化；玩家不是重复刷同一条任务，而是在验证新的规则假设。
- **失败反馈**：失败必须告诉玩家是哪条规则链断裂、哪个环境条件未满足，以及下次可以尝试的方向。

## 4. 探索世界：用发现推动成长

### 4.1 世界结构

世界由多个具有独立规则的区域组成，而不是一条线性任务地图。每个区域至少包含：

- 一种改变移动、战斗或资源获取方式的环境规则。
- 一条主探索路径和若干隐藏路径。
- 一个与区域规则相关的秘境或谜题。
- 一个能验证玩家 Build 的 Boss 或精英事件。
- 一条无法立即理解、需要带着新规则回来解读的线索。

### 4.2 规则驱动的探索门槛

探索门槛不只使用“等级不足”，而是使用规则问题：

- 没有“映照”规则时，看不见镜面迷宫中的真实道路。
- 没有“逆流”规则时，无法穿过倒流的灵脉区域。
- 没有“标记转化”规则时，无法读取隐藏在妖兽身上的遗迹坐标。
- 没有“环境适应”规则时，进入高温、寒域或毒雾区域会持续付出代价。

同一个区域尽量提供多种解决方案，让玩家用不同 Build 到达相同目标。

### 4.3 发现内容

- **机缘**：短期强力规则或一次性资源。
- **秘境**：规则主题明确的小型探索空间。
- **遗迹**：解释世界规则和历史的长期内容。
- **环境事件**：由天气、时间、地形或玩家规则组合触发。
- **Boss**：不是单纯血量更高，而是拥有一条需要被理解和破解的规则。
- **隐藏回访点**：获得新规则后，旧区域出现新的入口、解法或奖励。

## 5. 自动战斗与屏幕爽感

### 5.1 战斗定位

战斗采用实时自动执行。玩家的核心决策发生在战斗前和关键节点：

- 选择和排列规则。
- 决定携带哪些法宝、材料和技能。
- 在战斗中选择有限的规则切换、阵眼重排或风险操作。

战斗不是单纯观看，而是对探索成果的即时验证：玩家应当看见规则如何改变技能组合和战局结果。

### 5.2 爽感反馈层级

1. **局部反馈**：单个规则触发时，显示来源、对象和结果。
2. **连锁反馈**：多个规则连续触发时，用连线、数字轨迹和音效表现因果关系。
3. **Build 反馈**：完整循环成立时，短暂停顿并突出本次 Build 的核心规则。
4. **Boss 逆转**：破解 Boss 规则时，允许出现大范围特效、顿帧和战利品爆发。

满屏效果必须保留关键战斗信息：玩家能看懂“为什么变强”，而不是只看到颜色和数字。

## 6. 法则成长树、词缀与 Build 多样性

### 6.1 法则成长树

成长树不直接提供一条固定的最优路线，而是由三类方向构成：

- **生发**：复制、生成、召唤和数量增长。
- **转化**：改变物品、技能、资源和环境的属性。
- **吞噬**：消耗、压缩、牺牲和将敌方规则转为己用。

玩家可以在树上前进、横向连接或舍弃某些节点。强力节点应带来新的限制，避免所有玩家最终走成同一套 Build。

### 6.2 词缀系统

词缀附着在法宝、功法、材料和规则载体上，分为：

- **前缀**：改变基础行为或触发条件。
- **后缀**：改变联动方式、资源代价或成长方向。
- **隐性词缀**：通过探索、Boss 或特殊事件获得，通常改变系统规则。

词缀之间可以互相增强，也可以产生冲突。玩家需要在“更强的单条效果”和“更稳定的规则链”之间做选择。

### 6.3 不固定职业

劫掠者、炼丹师和寻脉者保留为初始倾向或探索身份，不再是不可改变的职业。玩家可以通过规则和词缀逐步混合出：

- 高速生成飞剑的剑意流。
- 低生命反转战局的逆境流。
- 通过材料转化不断发现新规则的炼化流。
- 牺牲装备和生命、吞噬敌方机制的破局流。

## 7. 修仙世界观与长期目标

- **炼气至筑基**：理解触发、条件和简单联动。
- **结丹至元婴**：建立稳定的规则链，开始改变区域规则。
- **化神至圣人**：获得规则转化和跨系统连接能力。
- **大帝境**：对世界底层法则进行局部改写，开启新的探索维度。

境界的主要奖励是新规则语法、新规则槽位、新探索方式和新 Build 空间。数值增长只负责支撑反馈，不作为唯一成长内容。

长期目标不是“堆到最高战力”，而是：

> **收集足够多的规则，理解世界为何如此运行，并最终获得改写天道的能力。**

## 8. 资源分配与内容循环

资源系统的核心不是让玩家不断刷同一种货币，而是让玩家在每次探索中回答三个问题：

1. **现在要不要把资源投入当前 Build？**
2. **要不要保留资源，换取更安全的撤离和更大的长期收益？**
3. **要不要接受更高风险，让规则组合获得更强的验证机会？**

资源因此分为“规则发现、局内构筑、探索风险、局外建设”四个层级。每个层级都有明确用途，不能用单一数值直接替代所有决策。

### 8.1 资源分层

| 资源 | 所属层级 | 主要用途 | 失败与离开时的处理 |
| --- | --- | --- | --- |
| **规则记录** | 规则发现 | 记录已发现的规则语法、触发条件、区域线索和 Boss 解法，扩充今后的可发现规则池 | 一旦完成发现即永久保留，不因失败丢失 |
| **法则碎片** | 局内构筑 | 装配、替换、升级和融合本次探索中的规则；也可支付规则冲突的临时修复费用 | 失败时大部分消失；成功撤离后可选择转化为永久规则研究进度 |
| **灵材** | 局内构筑／风险 | 修复法宝、重排阵眼、开启临时规则槽位、制作一次性探索工具 | 成功撤离可带回有限额度；超出携带额度的部分必须在营地处理或放弃 |
| **灵石** | 局外建设 | 营地基础设施、基础装备、规则鉴定和低阶材料补给 | 永久保留，但不能直接购买核心规则、Boss 解法或关键剧情权限 |
| **法则残页** | 局外建设 | 解锁新的规则语法、永久规则槽位、成长树节点和区域入口 | 永久保留；主要来自首次发现、Boss 和隐藏回访点 |
| **空潮** | 探索风险值 | 表示本次探索的规则不稳定程度，影响敌人、奖励、路线和事件，不是可无限囤积的货币 | 探索结束后清空或结算为风险评价；失败时只保留相关记录 |

规则记录和法则残页代表“我学会了什么”，灵石代表“我能建设什么”，法则碎片和灵材代表“本次能做到什么”，空潮则代表“我愿意冒多大风险”。

### 8.2 资源的互斥分配

同一批局内资源必须存在至少两种有吸引力的用途，避免最优解永远是直接升级攻击：

- **法则碎片**：可以立即装配一条临时规则，也可以用于融合规则碎片，或封存为研究进度。
- **灵材**：可以修复当前生存能力，也可以开启隐藏路径、扩充本次规则槽位，或制作撤离保护。
- **灵石**：可以购买低阶补给，也可以投入营地设施，解锁更稳定的规则鉴定和资源加工。
- **法则残页**：可以解锁新规则语法，也可以解锁新的探索工具；两者不能在早期同时快速完成。
- **空潮**：提高风险后可以获得更稀有的规则线索，但会改变敌人行为和区域条件；玩家可以消耗灵材降低风险，却会失去一部分即时构筑能力。

系统不应在界面上只显示“推荐花费”。应同时展示：立即收益、撤离价值、失败损失、对当前规则链的影响和可能开启的探索路线。

### 8.3 单次探索中的资源流转

1. **进入前分配**：玩家从局外库存选择少量初始规则、基础灵材和一次性工具，不允许把全部永久资源带入局内。
2. **探索中获取**：通过采集、战斗、事件和环境解谜获得法则碎片、灵材和规则线索。
3. **途中投入**：在营地、遗迹和规则节点之间决定修复、重排、扩容、融合或提高空潮。
4. **发现分流**：获得新规则后，选择“立即装配”“带回研究”“转化为材料”或“放弃并降低风险”。
5. **撤离结算**：主动撤离可以保留大部分已提取资源；继续深入则提高规则发现质量和空潮风险。
6. **失败结算**：已完成的规则记录、地图线索和 Boss 观察永久保留；未提取的局内强度和大部分局内资源消失。

失败不会清空玩家的理解，但会清空一部分没有成功带回来的物质收益。这样既保留 Rogue-lite 的风险，也保证每次失败都推动下一次探索。

### 8.4 三种典型资源决策

#### 剑意流：把资源投入即时验证

- 优先把法则碎片投入触发器、复制和范围扩展。
- 灵材主要用于开启战斗捷径和维持高速探索。
- 由于撤离保护投入较少，失败损失较高，但更容易快速验证规则链。

#### 逆境流：把资源投入风险管理

- 保留灵材用于护盾修复、低生命保护和撤离保险。
- 主动提高空潮，利用低生命条件换取更高质量的规则线索。
- 规则数量较少，但每条规则都围绕“受伤—转化—反击”形成稳定循环。

#### 炼化流：把资源投入长期发现

- 收集不同标签的灵材和残缺规则，不急于立即强化战斗。
- 使用资源开启遗迹、材料转化和隐藏回访点。
- 战斗能力可能较弱，但更容易发现新规则语法和永久法则残页。

三种路线应当获得不同类型的收益，而不是最后都换算成同一种攻击力。资源分配的结果应改变玩家能去哪里、能理解什么和能组合什么。

### 8.5 资源转换规则

- 局内资源转为局外资源时必须有损耗或额度限制，避免无限刷取和无风险滚雪球。
- 规则记录不能直接兑换成灵石；理解世界的奖励不能被经济系统完全替代。
- 灵石只能购买基础服务和低阶兜底资源，不能购买完整核心规则。
- 规则之间的转化应有明确标签、材料需求和失败反馈，不使用完全随机的资源吞噬。
- 同一条规则在一次触发链中不能无限递归复制；资源复制必须受次数、空潮或规则容量限制。
- 任何资源消耗都要在确认前展示消耗数量、保留数量和不可逆后果。

### 8.6 经济与内容循环原则

- 普通资源服务于探索、修复、构筑和承担风险，不替代规则发现。
- 首次发现、关键 Boss 观察和隐藏回访点提供稳定的永久进度，避免玩家因单次失败停滞。
- 商店提供低阶补给、鉴定和加工服务，不出售不可替代的核心规则。
- 后期若开放交易，只允许交易部分灵材、规则载体和非核心词缀；隐性规则、关键线索和 Boss 解法必须通过探索获得。
- 不用每日任务强迫玩家消耗某一种资源；日常内容最多提供补充和试验机会。

### 8.7 垂直切片的资源配额

首个版本先使用少量、可观察的配额验证资源决策，不急于引入复杂的货币数量：

- 每次出发携带 **2 条基础规则、3 个主动规则槽位和 1 个一次性规则槽位**。
- 每个主要探索节点至少提供一次“强化 Build、降低风险、换取线索”中的二选一或三选一。
- 每次探索保证至少出现 **1 次规则发现、1 个营地节点、1 个主动撤离点**。
- 灵材和法则碎片只在本次探索中循环，灵石和法则残页只在撤离结算后进入局外库存。
- 失败时保留规则记录和已查看的 Boss 机制，避免玩家因为一次资源判断失误而失去全部信息。
- 不设置限制进入次数的体力条；资源稀缺性来自“本次如何分配”和“是否继续深入”，而不是登录频率。

## 9. 首个可玩版本范围

首个垂直切片不追求大量内容，优先验证“探索获得规则、规则形成 Build、Build 改变探索”的闭环：

- 1 个主区域，包含 3 种环境规则。
- 1 个可回访的秘境。
- 1 个主 Boss 和 2 种破解方式。
- 12 条基础规则，覆盖触发、转化、连接和代价。
- 5 类可见资源：规则记录、法则碎片、灵材、灵石、法则残页；另有空潮风险值。
- 1 个主动撤离点和 1 个营地资源分配界面。
- 3 套可明显区分的 Build。
- 1 个小型法则成长树。
- 1 个能展示自动技能组合和连锁爽感的战斗场景。

垂直切片验收标准：玩家在不依赖任务箭头的情况下，能够发现至少一条规则，理解它的作用，组成一次有效联动，并用新规则到达原本无法到达的位置。
