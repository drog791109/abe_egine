## 管理规则

- 每个阶段开始前必须确认上一阶段的退出条件已经满足。
- 每个阶段中期安排一次可玩版本评审，优先判断核心体验是否成立。
- 每个阶段结束必须产出可运行版本、阶段复盘和下一阶段风险列表。
- P1 和 P2 是最高风险阶段。如果核心乐趣不成立，应优先返工规则和反馈，不继续扩内容。
- 新增系统必须能解释为什么服务于“探索未知、发现规则、组合规则、验证规则”的核心循环。
