# P4：天衍界 Demo

| 项目 | 内容 |
| :--- | :--- |
| 日期 | 2027-01-11 至 2027-05-02 |
| 时长 | 16 周 |
| 阶段目标 | 完成天衍界主要区域，形成 6-8 小时可试玩 Demo。 |
| 阶段结果 | 中央天域、南疆、西漠、北海、通天塔共同收束为五方灵潮主线。 |

---

## 一、阶段目标

P4 要把游戏从“东荒章节”扩展为“天衍界章节包”。此阶段重点不是开放所有地点，而是让玩家理解：

- 天衍界五方区域不是散点副本，而是同一座跨界大阵的节点。
- 每个区域都带来一种新环境规则和新构筑压力。
- 北海和通天塔完成从天衍界到内宇宙的过渡。

## 四、系统新增

| 系统 | 完成标准 |
| :--- | :--- |
| 天命格百分比 | 可把固定数值效果转为百分比收益，有清晰适用范围和限制。 |
| 航海探索 | 支持路线选择、天气事件、风险奖励、撤离和黑暗殿交易。 |
| 区域状态 | 灵脉修复、戒严、商路开放等状态能影响地图和商店。 |
| 声望雏形 | 皇朝、黑市、海族三方声望影响任务、价格和支援。 |
| 环境规则 | 毒雾、沙暴、逆流、时间切片至少各有一个可玩关卡。 |
| 伙伴祁照野 | 提供航路成本降低和灰色交易事件。 |

---

## 五、内容指标

- 新增地点：10-14 个。
- 新增道具：60-80 件。
- 新增规则：40-60 条。
- 新增敌人：15-20 种。
- 新增首领：4-5 个。
- 伙伴：祁照野加入。
- 主线时长：6-8 小时。

---

## 六、验收标准

- 玩家能明确说出五方灵脉属于同一座大阵。
- 至少 4 个地点在主线后发生视觉或玩法变化。
- 天命格百分比模式与倍增模式都有适合场景，不互相替代。
- 航海和通天塔共同推动跨界入口开启。
- Demo 可从新档开始连续玩到内宇宙入口。

---

## 七、交接到 P5 的条件

P4 结束必须具备：

- 稳定的多区域任务和传送框架。
- 阵营声望基础框架。
- 复杂环境规则接入能力。
- 天命格多模式切换能力。
- 6-8 小时内容的性能和存档稳定性。
