# P1：核心玩具原型

| 项目 | 内容 |
| :--- | :--- |
| 日期 | 2026-08-24 至 2026-09-20 |
| 时长 | 4 周 |
| 阶段目标 | 做出 5-10 分钟可玩玩具，验证背包规则构筑和自动战斗反馈是否成立。 |
| 阶段结果 | 玩家可以反复摆放道具、触发规则、进入战斗并理解结果差异。 |

---

## 一、阶段目标

P1 是整个项目的第一道生死门。它不看剧情完整度，不看美术完成度，只看核心玩具是否有趣：

- 拖拽和整理背包是否顺手。
- 不同摆法是否能造成明显结果差异。
- 天命格触发是否清晰。
- 自动战斗是否能让玩家看懂自己的构筑为什么有效。

## 三、功能细化

| 模块 | 必须实现 | 暂不实现 |
| :--- | :--- | :--- |
| 背包网格 | 拖拽、交换、旋转、占格、相邻关系、高亮预览。 | 批量整理、筛选、自动推荐、多页背包。 |
| 道具 | 形状、标签、基础效果、稀有度、描述。 | 完整强化、耐久、套装、多词缀掉落。 |
| 规则 | 战斗开始、击杀、受伤、相邻、次数增加、范围扩大。 | 复杂规则树、跨区域规则、长期污染。 |
| 天命格 | 固定位置、倍增模式、触发次数限制、触发反馈。 | 百分比、复制、移动天命格、规则污染。 |
| 战斗 | 自动攻击、敌人波次、血量、伤害、胜负、日志。 | 复杂 AI、地形、伙伴羁绊、首领多阶段演出。 |
| 探索 | 节点选择、战斗节点、奖励节点、撤离节点。 | 大地图、动态天气、阵营路线、隐藏回访。 |

## 四、内容细化

### 4.1 道具池

| 类别 | 数量 | 示例 |
| :--- | :--- | :--- |
| 法器 | 5 | 断锋、桃木剑、精铁剑、星砂匕、破甲锥。 |
| 符箓 | 4 | 聚灵符、引雷符、护身符、连环符。 |
| 丹药 | 3 | 回春丹、凝气丹、破障散。 |
| 材料 | 4 | 星核碎片、灵脉石、残缺阵纹、玄黑鳞。 |
| 阵盘 | 2 | 基础阵眼、引灵阵盘。 |

### 4.2 规则池

| 规则 | 类型 | 目的 |
| :--- | :--- | :--- |
| 相邻增幅 | Condition + Modifier | 教会位置关系。 |
| 战斗开始复制一次 | Trigger + Modifier | 教会天命格倍增爽点。 |
| 击杀生成剑气 | Trigger + Transform | 支撑剑意流雏形。 |
| 受伤转护盾 | Trigger + Transform | 支撑逆境流雏形。 |
| 丹药延迟触发 | Condition + Cost | 让玩家考虑时机。 |
| 符箓连锁 | Link | 让玩家看到规则链。 |
| 星核改变法器标签 | Transform | 引出落星谷资源概念。 |
| 污染一格换高收益 | Cost | 为后期空潮风险预埋。 |

### 4.3 战斗内容

- 普通敌人：灵脉虫、黑甲残影、星尘兽。
- 精英敌人：护阵傀儡。
- 测试首领：星核污染兽，会复制玩家最后一次触发的联动。
- 战斗时长：普通战 45-90 秒，首领战 2-3 分钟。

---

## 五、验收标准

- 5-10 分钟短循环可以从启动游戏连续玩到结算。
- 至少 3 种摆法会导致明显不同战斗结果。
- 天命格触发有视觉反馈、日志反馈和结算反馈。
- 首领复制玩家联动时，玩家能理解为什么被反制。
- 内部试玩后能列出前 10 个最高优先级问题。

---

## 六、交接到 P2 的条件

进入 P2 前必须冻结：

- 背包基础交互方案。
- 规则数据字段第一版。
- 自动战斗基础事件流。
- 战斗日志表达方式。
- 天命格倍增模式的基础限制。

如果 P1 结束后玩家不愿意反复调整背包，应延长 P1，而不是进入 P2。
