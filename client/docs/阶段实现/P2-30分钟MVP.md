# P2：30 分钟 MVP

| 项目 | 内容 |
| :--- | :--- |
| 日期 | 2026-09-21 至 2026-11-01 |
| 时长 | 6 周 |
| 阶段目标 | 完成序章到落星谷的 30 分钟纵向切片。 |
| 阶段结果 | 玩家能理解叶凡、沈青萝、天命格、太玄宗灭门和第一个追查目标。 |

---

## 一、阶段目标

P2 要把 P1 的核心玩具接成完整体验。它必须证明：

- 玩法不是孤立系统，而能服务剧情。
- 30 分钟内能完成目标、遭遇压力、调整构筑、获得成长。
- 玩家离开时知道下一次要去哪里、追什么线索。

---

## 二、周计划

| 周次 | 日期 | 重点 | 交付 |
| :--- | :--- | :--- | :--- |
| 第 1 周 | 2026-09-21 至 2026-09-27 | 序章灰盒 | 玄离王府地窖、太玄宗灭门、顾玄舟遗言。 |
| 第 2 周 | 2026-09-28 至 2026-10-04 | 地下灵脉教学 | 第一次背包整理、天命格觉醒、沈青萝登场。 |
| 第 3 周 | 2026-10-05 至 2026-10-11 | 荒古城据点 | 商店、任务板、身份牌拍卖、整备流程。 |
| 第 4 周 | 2026-10-12 至 2026-10-18 | 落星谷探索 | 节点路线、星核资源、精英事件、首领前置。 |
| 第 5 周 | 2026-10-19 至 2026-10-25 | 首领与结算 | 星兽首领、替身尸体线索、新目标结算。 |
| 第 6 周 | 2026-10-26 至 2026-11-01 | 试玩修正 | 新手引导、节奏修正、存档、Bug 修复和验收。 |

---

## 三、地点细化

| 地点 | 玩家动作 | 系统目的 | 剧情目的 |
| :--- | :--- | :--- | :--- |
| 玄离王府地窖 | 观看短过场、获得玉印记忆 | 建立身份悬疑 | 青铜门和母亲遗言。 |
| 太玄宗 | 逃离追杀、拾取断刃和符箓 | 给出基础道具 | 顾玄舟三句遗言。 |
| 地下灵脉 | 整理背包、触发天命格 | 教学核心玩法 | 天命格觉醒，沈青萝追问身份。 |
| 荒古城 | 购买补给、接受委托、调查身份牌 | 建立安全据点 | 皇朝追踪幸存者。 |
| 落星谷 | 探索星核、击败首领、发现尸体 | 验证第一套 Build | 替身尸体和玄离旧纹。 |

---

## 四、系统细化

| 系统 | P2 完成标准 |
| :--- | :--- |
| 背包 | 8x6 正式网格，可拖拽、旋转、交换、撤销一步。 |
| 天命格 | 倍增模式正式化，拥有说明、范围、高亮和冷却。 |
| 规则记录 | 发现后进入图鉴，可装配到道具或阵眼。 |
| 战斗 | 支持普通战、精英战、首领战，首领至少 2 个阶段。 |
| 探索 | 支持战斗、事件、奖励、商店和撤离 5 类节点。 |
| 剧情 | 支持对白、选择记录、短过场触发和章节目标更新。 |
| 存档 | 保存背包、道具、规则、剧情节点、地点解锁。 |
| 结算 | 展示获得内容、最高价值联动、下一目标。 |

---

## 五、内容指标

- 道具：30-40 件。
- 规则：20-30 条。
- 普通敌人：5-8 种。
- 精英：2 个。
- 首领：1 个。
- 剧情节点：12-18 个。
- 探索节点：8-10 个。
- 伙伴：沈青萝正式加入。

---

## 六、关键体验脚本

| 时间 | 玩家体验 | 内容 |
| :--- | :--- | :--- |
| 0-5 分钟 | 被卷入灾难 | 王府记忆、太玄宗灭门、顾玄舟交付残片。 |
| 5-12 分钟 | 第一次整理 | 地下灵脉里摆放断刃、聚灵符和回春丹。 |
| 12-18 分钟 | 规则奏效 | 天命格倍增断刃，击退灵脉妖兽。 |
| 18-24 分钟 | 进入据点 | 荒古城整备，身份牌拍卖暴露幸存者危机。 |
| 24-30 分钟 | 第一个钩子 | 落星谷星兽首领和叶凡替身尸体。 |

---

## 七、验收标准

- 新玩家 15 分钟内理解天命格倍增。
- 30 分钟内至少经历一次失败预警和一次构筑逆转。
- 落星谷首领至少能被 2 种 Build 击败。
- 玩家能说出下一目标：继续追查太玄宗幸存者和替身来源。
- 存档加载后能恢复玩家当前背包、规则和剧情进度。

---

## 八、交接到 P3 的条件

P2 结束必须沉淀：

- 可复用的探索节点配置。
- 可复用的首领阶段配置。
- 可复用的剧情节点配置。
- 可复用的结算界面。
- 新手引导问题清单和前 30 分钟流失点。
