| 项目 | 内容 |
| :--- | :--- |
| 日期 | 2027-09-20 至 2028-03-05 |
| 时长 | 24 周 |
| 阶段目标 | 补完外宇宙、混沌海、终章、多结局和周目回响。 |

---

## 一、阶段目标

P6 是内容完整阶段。重点不是继续增加新系统，而是让前面所有系统结算出来：

- 外宇宙禁地补完天命格、顾玄舟和远古文明真相。
- 混沌长城汇总阵营和宗门选择。
- 葬神渊让敌人学习玩家常用 Build。
- 初始之地根据长期行为判定结局。

## 四、终局系统

| 系统 | 完成标准 |
| :--- | :--- |
| 终局判定 | 伙伴、阵营、宗门、污染、记忆碎片、Build 记录共同决定结局。 |
| Build 学习 | 终局敌人读取玩家常用规则链，并生成针对性反制。 |
| 宗门结算 | 守门、开门、断因三条路线影响混沌长城支援。 |
| 伙伴结算 | 沈青萝、祁照野、玄镜的存活和羁绊影响终章可用能力。 |
| 多结局 | 至少 3 个主要结局和 1 个隐藏结局完整可触发。 |
| 周目 | 保留图鉴、配方和外观，重置部分关键因果关系。 |

---

## 五、内容指标

- 新增地点：16-24 个。
- 新增规则：80-120 条。
- 新增道具：120-180 件。
- 新增首领：10-14 个。
- 结局：3 个主结局 + 1 个隐藏结局。
- 全主线总时长：26-32 小时。

---

## 六、验收标准

- 从新档到任一结局可以完整通关。
- 终局判定不依赖单个最终按钮。
- 每个主要结局都有独立战斗或构筑差异。
- 周目回响能提供新的线索组合，而不是单纯提高数值。
- 完整 Beta 后不再新增大型系统，只进入发布打磨。

---

## 七、交接到 P7 的条件

P6 结束必须完成：

- 主线内容锁定。
- 结局条件锁定。
- 所有主要存档字段锁定。
- 已知严重 Bug 清单。
- 性能热点列表。
- 新手流失点和高难失败点列表。
