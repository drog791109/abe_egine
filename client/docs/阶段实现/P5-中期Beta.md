# P5：中期 Beta

| 项目 | 内容 |
| :--- | :--- |
| 日期 | 2027-05-03 至 2027-09-19 |
| 时长 | 20 周 |
| 阶段目标 | 完成内宇宙四域和外宇宙前半，验证中期系统复杂度。 |
| 阶段结果 | 阵营选择、高阶构筑、复制模式和空潮风险形成可持续中期体验。 |

---

## 一、阶段目标

P5 的核心是扩大世界，但不能让系统失控。玩家进入内宇宙后，应明显感到：

- 四大神域代表四套对秩序的理解。
- 阵营选择会改变路线、商店、首领和支援。
- 高阶规则带来更强 Build，但规则冲突和空潮风险开始逼迫取舍。

## 三、四域玩法细化

| 神域 | 主题 | 玩法压力 | 奖励方向 |
| :--- | :--- | :--- | :--- |
| 太虚神域 | 剑道与星辰 | 敌人不会被同一伤害方式连续命中。 | 单体爆发、剑意复制、精准斩断。 |
| 赤明神域 | 火道与炼器 | 不稳定融合会生成吞噬背包格的熔火。 | 高阶融合、火属性连锁、熔炼收益。 |
| 玄天神域 | 阵道与记忆 | 过去、现在和未来状态互相覆盖。 | 条件改写、镜像路线、规则校准。 |
| 幽冥神域 | 轮回与代价 | 角色死亡不一定失败，但会改变奖励和记忆。 | 复活、牺牲、生命转换。 |

## 四、系统细化

| 系统 | 完成标准 |
| :--- | :--- |
| 阵营 | 至少 4 个神域声望，选择影响路线、商店、支援和追捕。 |
| 高阶融合 | 支持稳定融合、不稳定融合、保护材料和失败产物。 |
| 规则冲突 | 当规则链互斥时，界面能显示冲突位置和原因。 |
| 复制模式 | 天命格可复制相邻道具功能影子，但受次数和污染限制。 |
| 空潮风险 | 风险影响敌人、奖励、路线和规则稳定性。 |
| 玄镜 | 伙伴技能可改变部分规则触发条件。 |

---

## 五、内容指标

- 新增地点：14-18 个。
- 新增道具：80-120 件。
- 新增规则：60-90 条。
- 新增敌人：25-35 种。
- 新增首领：8-10 个。
- 新增伙伴：玄镜。
- 新增主线时长：8-12 小时。

---

## 六、验收标准

- 四个神域试炼玩法差异明确。
- 玩家选择不同庇护方后，前 2 小时路线有明显变化。
- 复制模式足够强，但污染风险会让玩家主动克制使用。
- 中期至少 6 种 Build 能成立：剑意、丹道、符箓、召唤、炼化、破局。
- 外宇宙禁地能让玩家感到“规则开始不稳定”，而不是只感到敌人数值变高。

---

## 七、交接到 P6 的条件

P5 结束必须完成：

- 阵营选择记录和终局结算字段。
- 复制模式和空潮污染的长期记录。
- 禁地坐标点亮系统。
- 玄镜伙伴和规则条件改写能力。
- 中期所有主要 Build 的平衡基准。
