# P7：发布打磨

| 项目 | 内容 |
| :--- | :--- |
| 日期 | 2028-03-06 至 2028-04-30 |
| 时长 | 8 周 |
| 阶段目标 | 把完整 Beta 打磨为发布候选版本。 |
| 阶段结果 | 游戏稳定、清晰、性能达标，可以进入发布或平台审核准备。 |

---

## 一、阶段目标

P7 不再新增大型系统和主线内容。它只做四件事：

- 让新玩家看得懂。
- 让老玩家玩得顺。
- 让游戏稳定运行。
- 让发布版本可以持续维护。

---

---

## 三、打磨重点

| 类别 | 完成标准 |
| :--- | :--- |
| 新手引导 | 新玩家 15 分钟内理解拖拽、相邻、天命格倍增和战斗结算。 |
| UI | 规则描述、触发日志、道具说明、结算目标清晰可读。 |
| 手感 | 拖拽、旋转、交换、撤销、筛选、重排不打断心流。 |
| 战斗 | 自动战斗不会变成看不懂的光污染。 |
| 性能 | 常见配置下稳定帧率，长时间游玩无明显内存增长。 |
| 存档 | 升级版本后不丢主线、背包、规则、伙伴和结局进度。 |
| 平衡 | 每个阶段至少有 3-5 种有效 Build。 |
| 可访问性 | 字号、色彩区分、按键重绑、战斗速度控制可用。 |

## 四、测试清单

| 测试类型 | 覆盖范围 |
| :--- | :--- |
| 新档流程 | 从序章到落星谷、天衍界、内宇宙、终章各跑一轮。 |
| 存档兼容 | P6 Beta 存档升级到 P7 后正常加载。 |
| Build 回归 | 剑意、丹道、符箓、召唤、炼化、破局都能通关关键节点。 |
| 结局回归 | 3 个主结局和隐藏结局都可触发。 |
| 性能回归 | 高规则触发、高敌人数、高特效场景压力测试。 |
| UI 回归 | 不同分辨率、字号和语言长度下界面不遮挡。 |

---

## 五、发布候选标准

- 主线完整通关无阻断 Bug。
- 结局判定和周目开启稳定。
- 前 30 分钟引导通过至少 5 名新玩家测试。
- 规则触发日志能解释 90% 以上常见失败原因。
- 性能指标达到项目目标配置。
- 发布说明、已知问题列表和版本号完成。

## 六、P7 后续分支

发布后内容建议按小型赛季或免费更新拆分：

| 更新方向 | 内容 |
| :--- | :--- |
| 内容扩展 | 新禁地、新规则、新首领、新伙伴支线。 |
| 构筑扩展 | 新规则语法、新道具标签、新环境门槛。 |
| 周目扩展 | 因果回响新增事实偏移和隐藏路线。 |
| 品质更新 | UI、性能、操作、可访问性和文本校对。 |
